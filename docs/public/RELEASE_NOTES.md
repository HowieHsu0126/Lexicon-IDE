# Lexicon IDE 1.36.0

面向 Android 16 / API 36 的个人外刊阅读与学习工具。本次公开版本增加来源可追溯的雅思 Task 1 图表题，并完善个人电脑 Harness 配对与练习保存。

- 原文具备可比较数字时，生成分组柱状图或表格；每个数值绑定原文位置，再独立检查标签、单位与比较关系。数据不足时保留不可用状态。
- Task 1 与 Task 2 分别保存作文草稿；退出后可恢复，提交后再展示参考内容。
- 雅思生成、独立答题与解析审核使用三个 Harness Session。格式恢复和内容修订分别限额，未通过完整审核的题包不进入练习。
- 保留精读、略读、意群速读、离线 MDX 查词、语境卡、FSRS-6 与 Anki 快照导出。日间暖色、Dracula 夜间和200%字号已进行模拟器回归。

公开源码按 MIT 许可提供；字体和其他第三方代码保留各自许可。公开APK不含个人词典、Key、文章缓存或学习记录。用户可以导入自己有权使用的MDX词典。

本版APK使用调试签名，延续已交付个人版本的签名，可直接覆盖同签名旧版。它不是应用商店发行包。重新构建可能使用不同签名。

离线构建、759项JVM检查、Python两版本各676项、Harness插件88项通过；JVM另有11项跳过。模拟器数据回归42项、界面回归32项通过，并完成同一真实题包的日夜大字号试用与HTTPS读取。完整范围见[验收记录](VALIDATION.md)。

MagicOS真机、真实局域网、近期剑桥雅思整册覆盖、多样本生成质量及学习效果仍待验证。Task 1暂不含地图、流程图和多图组合；不提供官方Band预测或完整作文评分。
